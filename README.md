# MAPAAZ Luxury Hotel & Fine Dining

An ultra-luxurious, responsive boutique hotel & restaurant web application featuring warm ambient aesthetics, smooth micro-animations, interactive room carousels, and dual reservation capabilities (Suites & Dining Tables).

---

## 🌟 Features

- **Pixel-Perfect Luxury Aesthetic**: Warm gold/bronze accents (`#b88a58`), sleek dark overlays, and refined serif typography (`Cinzel`, `Cormorant Garamond`, `Plus Jakarta Sans`).
- **Interactive Hero Slider**: Full-bleed luxury bedroom slides with autoplay, manual navigation arrows, 5-star glow animations, and "Since 1998" heritage stats.
- **Value Proposition Highlights**: 4 interactive cards with custom line iconography and hover physics.
- **Story & Heritage Section**: Staggered dual-photo gallery and verified rating badges (Booking.com 4.9/5, Agoda 5/5, TripAdvisor 4.8/5).
- **Interactive Room & Suite Carousel**: Switch between Standard Room ($210), Deluxe Suite ($340), and Presidential Suite ($580) with real-time specs and direct booking integration.
- **Dedicated Fine Dining Section**: Michelin-inspired dining hall, signature degustation plating, and sky lounge mixology with meal timings.
- **Dual-Mode Reservation System**: Book hotel suites or reserve fine dining tables with instant toast feedback.
- **Location & Google Map Integration**: Featuring direct directions, helpline (`+91 75700 70035`), and live Google Map for **Tamkuhi Raj, Kushinagar, Uttar Pradesh**.
- **Interactive Video Tour Modal**: Ambient heated pool showcase with pulsing play button.
- **Fully Responsive**: Optimized for ultra-wide displays, laptops, tablets, and smartphones.

## 🚀 Getting Started

Simply open `index.html` in any web browser, or launch the included Node.js server:

```bash
node server.js
```
Then visit [http://localhost:3000](http://localhost:3000).
